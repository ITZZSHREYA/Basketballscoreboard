All CSS Background Properties

1. background: : Sets all the background properties in one declaration.

2. background-attachment: : Sets whether a background image is fixed or scrolls with the rest of the page.

3. background-clip: : Specifies the painting area of the background.

4. background-color: : Sets the background color of an element.

5. background-image: : Sets the background image for an element.

6. background-origin: : Specifies where the background image(s) is/are positioned.

7. background-position: : Sets the starting position of a background image.

8. background-repeat: : Sets how a background image will be repeated.

9. background-size: : Specifies the size of the background image(s).
